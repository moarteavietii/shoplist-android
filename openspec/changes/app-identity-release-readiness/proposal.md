## Why

The app still ships with the stock Compose template launcher icon (green Android robot) and the repo name as its launcher label, and the release build type has no signing configuration — a release APK cannot be installed on any device. Before the app can be used day-to-day as a finished product, it needs its real identity (icon, name) and a self-signed release build.

## What Changes

- Import the web project's PWA icon set (blue shopping cart with checkmark badge, `pwa-512.png` from `shoppinglist/apps/frontend/public/`) as the app launcher icon.
- Scale the imported artwork to the adaptive-icon safe zone (option A): foreground layer places the cart at ~66% scale on a white canvas; white becomes the background layer — no corner clipping on any launcher mask.
- Replace the legacy raster `mipmap-*/ic_launcher*.webp` fallbacks with densities generated from the new artwork.
- Rename the launcher label from `shoplist-android` to `shopy` (`app_name` string; plain ASCII by user decision — a diacritic variant was rejected for searchability).
- Add a release signing configuration: keystore generated by the user, passwords stored outside the repo (gitignored `local.properties` / `~/.gradle/gradle.properties`), `signingConfig` wired to the `release` build type in `app/build.gradle.kts`.
- Keep the existing monochrome (themed-icon) manifest entry; the monochrome layer renders the foreground silhouette (duotone art may look flat when wallpaper-tinted — accepted for now, verified on device).

## Capabilities

### New Capabilities

- `app-identity`: Launcher icon (adaptive layers, safe-zone compliance, legacy raster fallbacks), launcher label, and release-build signing configuration.

### Modified Capabilities

- `app-scaffold`: The launcher label requirement moves under the new `app-identity` capability; no behavioral requirement of `app-scaffold` changes (icon/label/signing were never specified there — this entry documents the boundary, expected to be an empty delta or dropped during spec creation if validation allows).

## Impact

- `app/src/main/AndroidManifest.xml` — no changes expected (icon/roundIcon/monochrome wiring already correct).
- `app/src/main/res/drawable/ic_launcher_foreground.xml`, `ic_launcher_background.xml` — replaced with new artwork.
- `app/src/main/res/mipmap-*/` — legacy webp fallbacks regenerated from the new icon.
- `app/src/main/res/values/strings.xml` — `app_name` → `shopy`.
- `app/build.gradle.kts` — release `signingConfig` reading keystore properties from gitignored sources.
- `local.properties` (gitignored) — new `shoplist.release.keystore.*` entries (path, passwords); keystore file itself stored outside the repo and backed up.
- Web repo (`shoppinglist`) — untouched; its maskable icons being byte-identical to the regular ones is a pre-existing PWA nit out of scope here.
